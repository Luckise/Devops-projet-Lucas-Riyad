# Design System: devops-project-lucas-riyad

## 1. Overview

**Creative North Star: "The EAT. Event Experience"**

This system is built for a vibrant, community-led event app. Drawing inspiration from the visual-forward curation of Fever, the fast-moving feed of Twitter, and the immersive browsing of Pinterest, the interface highlights the event's atmosphere. The aesthetic philosophy relies on an Off-White foundation to let high-impact imagery carry the emotion, while keeping interactions fast and highly responsive. It explicitly rejects the cluttered, spreadsheet-like feel of generic event listing sites.

**Key Characteristics:**

- Highly visual and immersive
- Fast, responsive feedback and seamless transitions
- Clear structural hierarchy bridging editorial engagement and product utility

## 2. Colors

The interface adopts a clean, approachable Off-White background. This provides a neutral, highly readable canvas that allows the vibrant event imagery and EAT. branding to pop without overwhelming the user.

**The Restrained Rule.** The surface rests on tinted neutrals (Off-White) allowing photography and specific UI accents to provide color.

## 4. Elevation

The interface uses flat surfaces by default. Because the motion energy is responsive rather than heavily choreographed, shadows appear only as a response to state (hover, focus) or to lift image cards slightly off the Off-White background.

## 6. Do's and Don'ts

### Do:

- **Do** prioritize high-quality event imagery over heavy UI chrome.
- **Do** use the Off-White background to create breathing room and elegance.
- **Do** make handoffs to external tools (like HelloAsso) feel intentional and trustworthy.

### Don't:

- **Don't** build cluttered, generic event listing sites (like basic Eventbrite templates) that feel like spreadsheets rather than experiences.
- **Don't** use pure stark white (`#fff`); always use the warmer Off-White for the background to maintain the EAT. brand feel.
